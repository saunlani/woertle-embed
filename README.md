# Woertle Embed

Embed [Woertle](https://woertle.com), the German Wordle with CEFR filters, directly onto your own website or blog.

## 🔧 How to Embed

Paste this HTML snippet into your site:

```html
<iframe
  src="https://woertle.com"
  width="400"
  height="675"
  style="border:none; overflow:hidden;"
  title="Woertle"
  allowfullscreen>
</iframe>
```

## ✨ Features
- Lightweight, responsive iframe
- Lazy loading for performance (optional)
- Great for educators, bloggers, and language learners
